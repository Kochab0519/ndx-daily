# 纳指 100 动态简报

每日发布的纳斯达克 100 指数动态简报，包含核心指标、关键事件解读、短期趋势判断和操作建议。

## 地址

https://kochab.ccwu.cc

## 内容结构

- **核心指标一览** — NDX、NQ 期货、VIX、A 股纳指 ETF 溢价等
- **关键事件解读** — 对当日重要经济/政策事件的中文大白话分析
- **风险事件预警** — 未来数日的关键数据或政策日程
- **短期趋势仪表** — 综合情绪判断
- **操作结论** — 明确的加仓/持有/观望建议

## 维护

本仓库托管于 GitHub Pages。直接编辑 `index.html` 并推送到 `main` 分支即可自动部署。

详见 [AGENTS.md](AGENTS.md)。
